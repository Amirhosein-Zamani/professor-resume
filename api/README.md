# Professor Resume API

نسخه 1.1.0 سرویس بک‌اند سامانه مدیریت و نمایش رزومه استادان دانشگاه دامغان است. این سرویس با NestJS 11، Prisma 7 و PostgreSQL 16 توسعه یافته و مسیر پایه آن `/api` است.

## راه‌اندازی محلی

1. فایل `.env.example` را به `.env.local` کپی و مقادیر واقعی را فقط در فایل محلی وارد کنید.
2. پایگاه داده PostgreSQL را اجرا کنید.
3. وابستگی‌ها، Prisma Client و Migrationها را آماده کنید.

```bash
pnpm install --frozen-lockfile
pnpm --filter api prisma:generate
pnpm --filter api prisma:migrate
pnpm --filter api start:dev
```

API روی `http://localhost:4000/api` و Swagger روی `http://localhost:4000/api/docs` در دسترس است.

## نقش‌ها و دسترسی‌ها

| عملیات | دسترسی |
| --- | --- |
| مشاهده دانشکده‌ها و رزومه‌ها | عمومی |
| ساخت و حذف استاد | فقط مدیر |
| ویرایش استاد، فعالیت‌ها و لینک‌ها | مدیر یا ویرایشگر همان رزومه |
| مدیریت دانشکده و طرحواره فرم | فقط مدیر |
| همگام‌سازی و Probe گلستان | فقط مدیر |

محدودیت نقش و مالکیت در API اجرا می‌شود و به مخفی‌کردن دکمه‌ها در رابط وابسته نیست.

## امنیت

- توکن‌های Access و Refresh در Cookieهای `HttpOnly` نگهداری می‌شوند.
- OTP با مولد رمزنگارانه ساخته و به‌صورت HMAC-SHA256 ذخیره می‌شود.
- درخواست و تأیید OTP برای ایمیل و IP محدود شده و ارسال مجدد دارای زمان انتظار است.
- عملیات پرهزینه گلستان فقط برای مدیر مجاز است و Rate Limit و ثبت رخداد دارد.
- فایل رزومه فقط با MIME، پسوند و امضای معتبر PDF پذیرفته می‌شود.
- SVG دانشکده از نظر عناصر اجرایی، ارجاع خارجی و داده جاسازی‌شده بررسی می‌شود.
- درخواست‌های تغییردهنده مرورگر فقط از `WEB_ORIGIN` پذیرفته می‌شوند.

رمزهای SMTP، JWT، پایگاه داده و گلستان نباید در Git ثبت شوند. برای محیط production از Secret Manager و HTTPS استفاده کنید و رمزهای افشاشده را فوراً تغییر دهید.

## آزمون و ساخت

```bash
pnpm --filter api build
pnpm --filter api test -- --runInBand
pnpm --filter api test:e2e
```

پیش از انتشار، Build تمیز، تست‌های مجوز، Migration، پشتیبان‌گیری و بازیابی باید در محیطی مشابه production اجرا شوند.
