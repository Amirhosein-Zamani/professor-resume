# مستند نیازمندی‌های داده برای صفحات فرانت

این فایل، لیست دقیق داده‌هایی که در هر صفحه پروژه Next.js نمایش داده می‌شود را مشخص می‌کند تا تیم بک‌اند بتواند APIهای مورد نیاز را طراحی کند.

---

## صفحه اصلی (Home) `/`
- **کامپوننت Hero**: فقط متن و تصویر ثابت (بدون نیاز به API).
- **کامپوننت SearchBar**:
  - لیست دانشکده‌ها (برای فیلتر)
  - لیست گروه‌های آموزشی (برای فیلتر)
- **کامپوننت Faculty**:
  - نمایش ۴ دانشکده (نام، تعداد اعضا، آیکون)
  - لینک به صفحه همه دانشکده‌ها

---

## صفحه لیست اساتید `/professors`
- **SearchBarHome**:
  - لیست دانشکده‌ها (برای فیلتر)
  - لیست گروه‌های آموزشی (برای فیلتر)
- **Card**:
  - لیست اساتید (برای هر استاد):
    - id
    - نام
    - مرتبه علمی
    - دانشکده
    - عضو هیئت علمی یا خیر
    - آواتار (آدرس عکس)
    - لینک‌های علمی (scholar, researchgate, scopus)

---

## صفحه پروفایل استاد `/professors/[id]`
- اطلاعات استاد:
  - id
  - نام (firstName, lastName)
  - ایمیل
  - آواتار
  - عضو هیئت علمی یا خیر
  - لینک‌های علمی (scholar, researchgate, scopus)
  - فایل CV (لینک دانلود)
  - آمار فعالیت‌ها:
    - تعداد کل فعالیت‌ها
    - تعداد مقالات علمی
    - تعداد پایان‌نامه‌ها/رساله‌ها
- **فعالیت‌ها (ActivitySection)**:
  - گروه‌بندی شده بر اساس نوع (مقاله، کتاب، طرح پژوهشی، پایان‌نامه و ...)
  - برای هر فعالیت:
    - id
    - نوع فعالیت (type)
    - عنوان فارسی (titleFa)
    - عنوان انگلیسی (titleEn)

---

## صفحه دانشکده‌ها `/faculties`
- لیست دانشکده‌ها:
  - id
  - نام دانشکده
  - تعداد اعضا
  - آیکون (یا نام آیکون)

---

## صفحه درباره ما `/about-us`
- فقط متن ثابت (بدون نیاز به API)

---

## صفحه تماس با ما `/contact-us`
- اطلاعات تماس ثابت (آدرس، ایمیل، تلفن)
- فرم تماس:
  - ارسال اطلاعات فرم (نام، ایمیل، موضوع، پیام) به سرور

---

## جمع‌بندی APIهای مورد نیاز
1. **GET /faculties**
   - خروجی: لیست دانشکده‌ها (id, name, count, icon)
2. **GET /professors?faculty=&group=&name=**
   - خروجی: لیست اساتید با فیلتر (id, name, rank, faculty, isFaculty, avatar, links)
3. **GET /professors/{id}**
   - خروجی: اطلاعات کامل استاد (id, firstName, lastName, email, avatar, isFaculty, links, cv, activities[])
4. **GET /groups**
   - خروجی: لیست گروه‌های آموزشی (id, name, facultyId)
5. **POST /contact**
   - ورودی: نام، ایمیل، موضوع، پیام
   - خروجی: وضعیت ارسال
