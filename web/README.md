# Professor Resume Web

نسخه 1.1.0 رابط عمومی و داشبورد سامانه رزومه استادان دانشگاه دامغان است. این برنامه با Next.js 16.2، React 19.2 و Tailwind CSS 4 توسعه یافته است.

## راه‌اندازی محلی

فایل `.env.example` را به `.env.local` کپی کنید، آدرس API، آدرس اصلی سایت و نام کوکی Refresh را با API یکسان نگه دارید و سپس برنامه را اجرا کنید.

```bash
pnpm install --frozen-lockfile
pnpm --filter web dev
```

برنامه توسعه روی `http://localhost:3001` اجرا می‌شود و API پیش‌فرض روی `http://localhost:4000/api` قرار دارد.

## ساخت production

```bash
pnpm --filter web lint
pnpm --filter web build
pnpm --filter web start
```

## ساختار اصلی

- صفحات عمومی برای خانه، فهرست دانشکده‌ها، جست‌وجوی استادان و رزومه عمومی
- ورود بدون گذرواژه با OTP ایمیلی
- داشبورد واکنش‌گرا برای مدیریت استادان، دانشکده‌ها و فرم‌ها
- مؤلفه‌های مشترک برای Select جست‌وجوشونده، شیت موبایل، تأیید حذف و بارگذاری فایل
- تنظیمات SEO برای صفحات عمومی و جلوگیری از ایندکس داشبورد

## کنترل کیفیت

پیش از تحویل، مسیرهای عمومی و داشبورد در اندازه موبایل، تبلت و دسکتاپ بررسی شوند. سناریوهای ورود، انقضای OTP، خطای فرم، فایل نامعتبر، حذف دانشکده دارای استاد و دسترسی ویرایشگر به رزومه دیگر باید در تست پذیرش پوشش داده شوند.
